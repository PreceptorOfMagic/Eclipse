Licence statement
-----------------
The pinned upstream README says the Unscii material may be considered public
domain or CC0, except for unifont.hex, hex2bdf.pl and unscii-16-full.* because
those files derive from or contain parts of Roman Czyborra's Unifont project
and fall under the GPL. The embedded Unscii-8 asset identified below is not one
of those named exceptions.

Material redistributed by this project
--------------------------------------
LVGL first imported the built-in Unscii-8 glyph array in commit
5168b5c44f284e647c20a6694010b218fc323950 (26 June 2019). That source identifies
the font as Unscii and links the historical project page at
http://pelulamu.net/unscii/ . LVGL later added the TTF used by its font-generation
script in commit 4f70bbf182421b2a4879e02fbf732df181489315 (8 March 2021).
